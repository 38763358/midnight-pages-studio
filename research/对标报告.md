## 1. 每家可以借鉴的 3 点
**Rifle Paper Co.**
1. 首屏是一整张满版实拍：真的包装纸、彩带和卡片铺满一桌，文字只占中间一个小牌子。
2. 导航很密：顶部促销条，Logo 居中，下面 9 个品类和 Sale。看着就是一家真在营业的店。
3. 按季节讲故事（Holiday Collection），商品行就是普通的方形图配名称和价格，没有任何装饰。

**Papier**
1. 首屏是人物手里拿着产品的生活照（手、毛衣、窗光），人和场景先于产品出现。
2. 标题字号克制（约 40px），衬线斜体只点一个词："The GIFT of good plans."
3. 紧接着就是"Shop the collection"商品横排，第一屏就能买。

**Minted**
1. 用纸张和织物的极近特写传达材质，画面上几乎没有字。
2. 文案只有一句（For every life moment）加一行副标。
3. 按"场合"分类（Holiday / Wedding / Baby / Parties）。这正对应我们的买家：中介按场合送礼。

**Appointed（appointed.co）**
1. 桌面俯拍：笔记本、钢笔、咖啡杯、窗影，自然光，颜色很淡。
2. 标题用普通字重的衬线体，左对齐，不加粗也不放大。
3. 整页偏安静：灰绿和米白，按钮是小号深色矩形。

**Sugar Paper**
1. 产品平放在白底上实拍，配一句直白的话（"2027 Planners Are Here!"）。
2. 用媒体报道 logo 做信任背书。我们没有，不能编。
3. 大量真实使用照（手写、礼物），商品格子朴素。

**Smythson**
1. 棚拍产品群组，灯光讲究，以质感取胜。
2. 皇家认证徽章放在角落，克制。
3. 深色品牌底配细字距全大写导航，高级感来自摄影和留白，不是排版花样。

**Mount Street Printers**
1. 首屏放印刷机和车间的真实照片，讲"手艺"。
2. 唯一一家动效比较多（滚动展示印刷工艺），但动效服务于讲工艺。
3. 字体只有一套，层级少。

### 它们的共同点（为什么不像 AI 做的）
| 维度 | 它们怎么做 |
|---|---|
| 摄影 | 100% 真实场景：桌面、手、礼物、窗光、景深。产品出现在"用的时候"，不是悬在空中的样机 |
| 导航和密度 | 促销条加居中 Logo 加一整排品类，第一屏就有商品。信息密度高，像一家店 |
| 字体 | 一套衬线加一套无衬线，标题 36–48px，只有个别地方用斜体。没有 100px 以上的巨型标题 |
| 留白 | 留白很多，但留在图片四周，文字区反而紧凑 |
| 配色 | 颜色主要来自照片本身，界面色只有米白、深色和一个强调色 |
| 商品展示 | 普通方形或竖长方形图，下面写名称和价格。没有倾斜，没有投影，没有拼贴 |
| 文案 | 短、具体、带季节和场合（Holiday、2027 Planners、For every life moment） |
| 动效 | 几乎没有。轮播、悬停换图就够了 |

## 2. 我们的 AI 味来源清单（诚实版）
1. **没有一张真实场景照片。** 全部是产品图本身（排好版的平面图），再套一层 CSS 倾斜和阴影。这是最根本的问题。
2. **巨型衬线标题加斜体第二行加小号全大写眉题**，每一段都重复这套"Eyebrow / Big serif / *italic*"，是 AI 落地页最典型的套路。
3. **样机倾斜加多层投影**，看着像"设计师作品集里的展示图"，不像商店。
4. **拼图式产品图：** Library 的图是 8 张吊牌排成格子的拼图，再塞进样机，就成了图中图。
5. **装饰性大数字"93"**、罗马数字 I/II/III、金色细线：这些"编辑感"装饰没有内容支撑。
6. **"Drag or swipe to leaf through"的卡叠手势**：炫技，真实纸品店没人这样卖东西，而且一次只能看一个系列。
7. **导航太空**：只有 4 个锚点和一个按钮，没有季节或场合入口，像单页作品集，不像店。
8. **文案缺少季节感和场合感**：明明是"感恩节派饼、圣诞礼物"的生意，首屏却在讲"109 designs"。
9. **段落节奏太均匀**：每段一样的上下留白、一样的左右分栏，一眼就能看出模板感。
10. **手机端只是把电脑版纵向堆叠**，没有像 Papier 和 Rifle 那样首屏就是一张图加一个按钮。

## 3. 没有实拍照片怎么办（免费、合规）
| 办法 | 合规性 | 效果 | 结论 |
|---|---|---|---|
| A. AI 生成"空白吊牌"的写实场景，再把真实吊牌图透视贴上去 | 生成图可以商用（按所用工具的条款），吊牌是自家设计 | **最好**：可以按需生成门廊苹果袋、感恩节派饼、圣诞饼干等，光线和景深统一 | **推荐**。本次生成了两张空白吊牌场景（门廊苹果纸袋、桌上派饼加棉绳吊牌），画面很真实，但生成工具的输出文件没有落到这台共享电脑上，没能完成合成。下一步请主 agent 生成图片，或者换一个能存文件的生成方式，再由我合成 |
| B. Unsplash / Pexels 免费可商用照片再合成 | Unsplash License 允许商用，不必署名 | 很难找到"正好有一张空白吊牌、角度合适"的照片 | 这台电脑上 Unsplash 接口被拦了，没能下载 |
| C. Wikimedia Commons 的 CC BY 照片再合成 | 要署名 | 本次验证用了这个，见 `场景合成-派饼.jpg` | **效果一般**：照片的景深、光线和吊牌对不上，近看能看出是贴的。只适合做示意 |
| D. 免费 PSD 样机（Freepik、Mockups-Design、Pixeden 免费区）加 Photopea（免费网页版 PS）换图 | 多数要署名或限个人用，要逐个看授权 | 专业样机的光影最真实，但场景大多是"桌面平铺"，节日场景少 | 可以作为补充，需要人工操作 Photopea |
| E. 自己拍（打印吊牌，拿手机在窗边拍） | 完全合规 | 最真 | 不花钱，但需要老板或同事拍。**强烈建议至少拍 3 张** |

验证样图：`场景合成-派饼.jpg`。底图是 Wikimedia Commons 上的 "Apple pie 7.jpg"，CC BY 4.0，上线要署名。上面透视贴了 Curb Appeal 的 "Thankful" 吊牌，加了投影、模糊和颗粒。结论：**能用来演示方向，正式上线建议走方案 A 或 E**。

## 4. 新方向
**一句话定位：** *像一家街角纸品店的季节橱窗。先让中介看到"这张吊牌系在派饼上、放在客户门口"的画面，再让他买。*

**从上到下的版式草图**
1. **顶部深蓝促销条**：Instant download via Gumroad · Nothing ships; everything prints · Get ten free prompts（全部是现有文案）。
2. **刊头**：左边 Search（可以先做成跳到商品区的锚点），中间小字距 wordmark，右边 Gumroad shop。下面一排按场合和品类的导航：Thanksgiving pop-bys / Gift tags / The Tag Library / Prompt Pack / Free sample。
3. **首屏满版实景图**（方案 A 或 E 产出的派饼或门廊苹果袋），角落叠一小块文字："The Pop-By Tag Library · $39 / For the pie at Thanksgiving. / Buy the Library"。标题约 46px，不再用巨型字。
4. **商品横排 "Gift tag sets, $7 each"**：8 个系列做成普通方形图配名称和价格，电脑一行 4–5 个，手机一行 2 个，可以横滑。没有倾斜、没有投影、没有卡叠手势。
5. **"How agents use them"改成三张场景照**（门廊 pop-by / 成交周年 / 开放日柜台），每张配原有的一句文案。用图片讲，不用罗马数字。
6. **Tag Library 详情段**：左边大实景图，右边原有文案、$39 按钮和"All eight sets bought separately cost $56"。
7. **Prompt Pack**：深蓝底，封面图平放实拍或样机，加原文案和 $24 按钮。
8. **Free sample**：一行横幅加按钮。
9. **页脚**：现有链接。

**动效**：只保留图片加载时的淡入、商品图悬停时轻微切换到第二张图（如果有），其余全部去掉。

**效果图**：`新方向首屏.png`（1440 宽）、`新方向首屏-390.png`（手机），源文件是 `新方向首屏.html`。首屏图暂时用的是方案 C 的示意合成图，标了"示意"。
